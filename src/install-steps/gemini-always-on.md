# Claudovsky for Gemini — always-on

Copy-paste into "Saved info," no download, no account beyond Gemini itself. Two minutes, once, and it applies to every conversation from then on. Want it for just one chat instead? See [`per-session.md`](./per-session.md).

## Setup

1. Open Gemini and log in.
2. Click your profile picture (top right) → **Saved info** (in some versions this is under **Settings → Saved info**, labels shift between rollouts).
3. Click **Add** (or the "+" for a new saved item).
4. Paste the whole block below as one saved-info entry.

{{INSTRUCTIONS_BLOCK}}

5. Save. Done — every new conversation now has Yiddish flavor by default.

**To turn it off later:** delete that saved-info entry, or type "Stop speaking like Claudovsky" in any chat for that conversation only.
